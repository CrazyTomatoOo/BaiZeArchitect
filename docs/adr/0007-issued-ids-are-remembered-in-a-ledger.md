# 条目编号只增不减：发号账本记「发过什么」，层目录只回答「现在有什么」

`baize new` 过去只看层目录第一层的文件名来发号（`max(文件里的号) + 1`），于是**删掉或搬走最后一个条目就会退号**——下一个新条目拿到同一个编号，指着旧编号的 `parent` / `covers` / `refines` 静默改指到新条目。本 ADR 记的是发号这件事的纪律：编号一旦发出去就不再复用，而「发过什么」必须落在盘上（#193）。

**决定**：四条。

1. **发号取大者 +1，先记账再落盘**：新号 = max(账本记的最大号, 层目录里现有的最大号) + 1。账本在条目文件写下去**之前**更新——号一旦发出就不再复用；半途失败只留一个空洞（没人用的号），不留一次复用。
2. **账本 `baize/ids.yaml` 由 CLI 拥有**：每层一行「已发出去的最大编号」，只增不减。它记的仍是**算不出来的东西**（目录能算出「现在有什么」，算不出「发过什么」），与链状态文件同一条纪律。缺账本 = 老仓库：第一次发号按各层目录现状补基线，手写条目照旧继续用，不必先跑迁移。
3. **账本读不懂就拒绝发号**：形状不对 → `baize new` exit 2、目录零变化，`validate` 报 `id.ledger-invalid`（ERROR）。宁可不发号，也不冒复用编号的险。
4. **条目发现规则写死，且不再静默**：只有层目录**第一层**的 `.md` 是条目；子目录与非 `.md` 文件不是条目，`validate` 用 `id.stray`（WARNING）点名。搬目录不再是无声操作。

## 为什么需要它

`CONTEXT.md` 的 `id` 词条承诺编号「永不变」，`acceptance` 词条的线索编号稳定性（删掉的不复用）也垫在这上面——**实现过去没有兑现这条承诺**。#193 的实测：删掉 `IR-001` 后 `baize new ir` 又发出 `IR-001`，`SR-001` 的 `covers: IR-001#a1` 于是指向一条完全不相干的新需求，报告里只剩一句语义说反的「下游待复核」（说的是「上游改过」，实际是「换了一条」），一次 `baize accept` 就抹平。同一处的第二半：模型只扫层目录第一层，所以「归档」只能退化成**搬走**或**删掉**——搬走是彻底的静默（`validate` / `status` / 覆盖率都看不见它），而且同样退号。

## Considered Options

- **不落账本，靠 git 历史推**：否。git 记的是「文件曾经叫什么」，不是「这个号发过」；本套件不该要求仓库是 git 仓库，发号之后也可能还没提交。
- **账本改记「发过哪些号」的完整集合**：否（暂）。集合只多认出一种情形——手写出来、又被删掉的号；而「CLI 发过、后来删掉」的号在集合里同样看不出复用（号还是那个号，内容换了）。收益窄，文件却随条目数线性长大；先要最大号。
- **账本记内容指纹**：否。那是另一件事（判「这条还是不是原来那条」），已有的 `confirmed` / `reviewed` 指纹在做。
- **禁止手写条目，一律走 CLI**：否。纯文本、手写可用是这套模型的底线（ADR-0002）。
- **递归扫描子目录，把搬走的条目找回来**：否。ADR-0002 已定「目录是位置、`parent` 才是语义」；递归会让「归档目录」变成一种隐式状态维度，等于凭空引入模型里没有的「退役」概念。改为：点名，但不算条目。
- **账本缺失报 WARNING**：否。老仓库升级过来必然没有账本，报了也修不好，只会让 `--strict` 长期红着；第一次发号自动补基线即可。

## Consequences

- 「编号永不变」从一句话变成**可断言的行为**：删掉或搬走条目之后再发号，号不回退，旧引用继续报 `ref.*`（#193 验收线索 1、2）。
- 用户仓库里多一个 CLI 拥有的文件 `baize/ids.yaml`。它只记编号，不记进度、覆盖率、陈旧。
- **残余风险照旧**：手写一条与已删条目同号的文件，模型分辨不出来——编号就是身份，账本只记号不记内容。要认出这一层得靠下游的 `reviewed` 指纹（`stale.direct-downstream`）或 git 历史。
- **「归档」仍然不是模型里的动作**：搬目录现在会被点名，但退役这件事依旧没有维度（要说得清「退役条目还算不算覆盖率与陈旧的分母」，那是另一个决定）。
- 层目录里出现陌生路径（子目录、随手记的笔记文件）不再是静默事件：`validate` 报 `id.stray`，`--strict` 会红。隐藏文件（`.` 开头）不报——那是编辑器与系统留下的，不是信号。
