# Use G6 and ELK as the free C4 canvas stack

Status: accepted

BaiZeArchitect uses MIT-licensed AntV G6 for graph rendering and interaction with ELK.js Layered for compound hierarchical layout. BaiZeArchitect owns projection-to-layout mapping and deterministic standalone SVG/2× PNG generation; the 500-node Lit/Vite gate passed, and Cytoscape.js plus ELK.js or JointJS plus ELK.js are not automatic fallbacks.
